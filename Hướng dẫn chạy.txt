Bước 3: Tạo database


 Mở PowerShell tại thư mục project rồi chạy:

sqlcmd -S "localhost\  ( tên sever của máy ) " -E -I -f 65001 -i "database\01_TaoBang_Khoa.sql"
sqlcmd -S "localhost\  ( tên sever của máy ) " -E -I -f 65001 -i "database\02_DuLieuMau.sql"


Thay SQLEXPRESS bằng tên instance của máy đó.
-f 65001 giúp đọc đúng tiếng Việt (UTF-8).
-I bật QUANTIFIED_IDENTIFIER, vì các script cần tuỳ chọn này.
Lưu ý: file 01 sẽ xoá database QuanLyBanhMi cũ nếu đã có rồi tạo lại. File 02 chạy trong một transaction, nên nếu lỗi ở đâu thì toàn bộ dữ liệu sẽ được rollback.

Bước 4: Người nhận phải sửa code
Sửa connection string ở dòng này:

nó ở data / DatabaseHelper.cs

"Server=localhost\\SQLEXPRESS01;Database=BanhMiShopDB;Trusted_Connection=True;TrustServerCertificate=True;";


Cần đổi 2 chỗ:

SQLEXPRESS01 thành tên instance trên máy họ.
BanhMiShopDB thành QuanLyBanhMi.
Viết lại các câu SQL theo bảng mới, ví dụ bảng TaiKhoan, VaiTro, NhanVien thay cho Users, Roles, Employees. 
Trước mắt là câu đăng nhập trong btnLogin_Click của FormLogin.cs. 
Dòng thông báo "Kết nối tới CSDL BanhMiShopDB thành công!" ở nút kiểm tra kết nối cũng nên đổi tên cho khớp.

Bước 5: Chạy app
Mở BaiTap_WinForms.slnx bằng Visual Studio rồi bấm F5.
 Visual Studio sẽ tự tải package Microsoft.Data.SqlClient qua NuGet, nên máy cần có mạng.
 Bấm nút kiểm tra kết nối trên form đăng nhập trước để xem đã kết nối được database chưa.
